# dup-remover

Учебный проект на Rust для команды из двух человек: утилита поиска дубликатов файлов.

Минимальная версия рекурсивно сканирует папку, сравнивает файлы по размеру и хешу
содержимого, показывает группы дубликатов и сохраняет JSON-отчёт. Ошибки чтения
отдельных файлов записываются в предупреждения. Файлы не удаляются автоматически.

## Разработка

```sh
cargo build --locked
cargo fmt --all -- --check
cargo clippy --locked --all-targets --all-features -- -D warnings
cargo test --locked --all-targets
```

Реализация разделена на два issue и два PR: движок сканирования и CLI с отчётами.
Основная ветка — `master`. Каждый PR ссылается на своё issue и вливается через
**Rebase and merge** после проверок.
