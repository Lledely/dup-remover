Готовый установщик для **Windows 10/11 x64**: скачайте файл
`dup-remover-<версия>-windows-x64-setup.exe` из Assets и запустите его.

- Установка для текущего пользователя, без прав администратора.
- Rust, Cargo и отдельный Visual C++ Redistributable для запуска не требуются.
- Добавление программы в пользовательский PATH можно включить при установке.
- Удаление через «Параметры → Приложения» сохраняет чужие записи PATH и созданные пользователем файлы.
- Рядом с установщиком находится файл с контрольной суммой SHA-256.

После установки откройте **новое** окно PowerShell:

```powershell
dup-remover --help
dup-remover scan "C:\Users\Name\Downloads" --jobs 4 --output report.json
```

Установщик не подписан сертификатом Authenticode. Эта версия выполняет поиск
дубликатов и создаёт отчёты; файлы остаются на месте.
