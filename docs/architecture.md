# Контракт модулей

Библиотека `dup_remover` предоставляет `scan(root, &ScanOptions) -> io::Result<ScanReport>`.
CLI вызывает библиотеку и выводит результат. Реализация программы — на Rust.

## Движок

- `ScanOptions { min_size: u64, jobs: usize }`: порог в байтах, число рабочих потоков.
- `jobs = 0` — ошибка параметров. Значение по умолчанию — доступное число потоков.
- Корень должен быть существующей папкой. Символические ссылки не обходятся.
- `scanned_files` и `scanned_bytes` считают обычные файлы, прошедшие фильтр размера.
- Сначала группировка по размеру, затем потоковое вычисление BLAKE3 для кандидатов.
- Файлы хешируются параллельно; число рабочих потоков ограничено `jobs`.
- Ошибка корневой папки возвращается как `Err`; ошибки отдельных записей — как
  `ScanWarning { path, message }`, сканирование продолжается.
- Группы `DuplicateGroup { size_bytes, hash, paths }` содержат минимум два пути.
- Результаты сортируются для воспроизводимости последовательного и параллельного запуска.
- `ScanReport` сериализуется через Serde. Методы `duplicate_files` и `reclaimable_bytes`
  считают лишние копии при сохранении одного файла в каждой группе.

## CLI

```sh
dup-remover scan <PATH> --min-size 1MB --jobs 4 --output report.json
```

- `--min-size`: байты или целые размеры с суффиксами KB/MB/GB и KiB/MiB/GiB.
- `--jobs`: положительное число потоков.
- `--output`: JSON-отчёт; без параметра показывается только текстовый отчёт.
- Отчёт показывает группы, количество файлов, объём лишних копий и предупреждения.
- Успешное сканирование, в том числе с предупреждениями: код 0. Ошибка запуска или
  записи отчёта: ненулевой код. Справка и версия доступны через стандартные флаги.

## Границы первой версии

Удаление и перемещение файлов, TUI, прогресс и бенчмарки — возможные следующие issue.
Оценка освобождаемого места основана на размерах файлов и не учитывает общие блоки
жёстких ссылок, сжатие и особенности файловой системы.
